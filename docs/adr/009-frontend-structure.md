# ADR-009: Структура frontend и работа с данными

- **Статус:** Принято
- **Дата:** 2026-11-09

## Контекст

`web` — Next.js 16 (App Router) без доступа к БД ([ADR-001](001-system-topology.md)). Аутентификация — cookie-сессии через прокси `/api/*` с проверкой `Origin` ([ADR-005](005-authentication-sessions.md)). Контракт — OpenAPI и openapi-fetch ([ADR-007](007-api-contracts-errors-validation.md)). Бизнес-правила не должны дублироваться между frontend и backend.

## Варианты

### Изменение данных

- **Server Actions** → API сервер-сервер: Next-native, но второй путь изменения данных; для него отдельно нужно решать CSRF-проверку (нет `Origin` браузера), проброс cookie и разбор Problem Details.
- **Из браузера через `/api/*`**: один путь для всех изменений с одинаковыми правилами безопасности и ошибок.

### Отображение доступных действий

- **Условия на frontend** (`status` + дедлайн): дублирование бизнес-правил, расхождение при их изменении.
- **Вычисленный API список `allowedActions`**: правило в одном месте — в домене.

### Адрес публичной страницы

- `/{slug}` в корне: короткий адрес, но конфликт с будущими маршрутами и список зарезервированных слов.
- `/book/{slug}`: без конфликтов.

## Решение

- Чтение: Server Components с серверным клиентом API; интерактивные данные — TanStack Query + openapi-fetch.
- Изменения — только из браузера через `/api/*`. Server Actions для изменений не используются.
- API возвращает `allowedActions` для текущего пользователя; frontend показывает действия только по нему.
- Публичная страница — `/book/{slug}`.
- Структура: `app/` (тонкие маршруты) → `features/*` → `shared/*`.

Подробности — [frontend.md](../architecture/frontend.md).

## Последствия

- Ответы API с бронью содержат `allowedActions` и `cancelDeadlineAt`; доменная функция «доступные действия» используется и для ответа, и для проверки в use case.
- Время на публичной странице рендерится на клиенте (пояс браузера неизвестен серверу).
- Если в будущем понадобятся Server Actions, потребуется отдельное решение по CSRF для серверного пути.
